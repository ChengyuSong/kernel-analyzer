# Transfer summaries (--func-summaries): callsite-applied atoms.
# Line: <name>[*] ATOM [ATOM...]    '*' suffix = prefix match.
# Ordered, FIRST MATCH WINS (NONE lines carve exclusions out of a
# following prefix rule). Atoms:
#   FRESH            per-callsite heap object (drives AllocFuncs paths)
#   CPY(ret<-argN)   shift-preserving cell copy into the result
#   ALIAS(ret=argN)  result aliases the argument value
#   ST(*argC<-argV)  store value argV into *argC
#   LD(ret<-*argC)   result loaded from *argC
#   NONE             explicitly no summary (body analyzed)
#   NOOP             no transfer at the callsite AND body skipped
#                    (standalone; replaces hardcoded free/utility lists)
#
# Provenance: migrated 2026-07-24 from the hardcoded isAllocFn table
# (src/lib/Annotation.cc) — task #26 — plus the dup family with copy
# semantics (CPY), fixing the measured copy-loss (t_kmemdup.c was 0/2:
# kmemdup sat in isAllocFn, its body was skipped, the memcpy dropped)
# and suppressing the shared allocator return-node channel (~470
# witnessed cross-caller joins at km).
#
# ASSUMPTIONS (recorded):
# - CPY models aligned whole-buffer dup from offset 0; prefix copies
#   over-approximate soundly.
# - *_user dup/copy sources are userspace memory: kernel fptrs must
#   never round-trip through user memory (same assumption as uaccess
#   asm), so those get FRESH without CPY.

# Container APIs summarized so their bodies (unknown-index bucket walks,
# list traversals) stop pooling every instance's payload. The dispatch
# sites inside the bodies keep their identity through DISPATCH atoms
# (the SoK ground truth keys hash.c:253/272/383/805/833 and
# linked-list.c:87/111/128 by those sites). Layout (x86-64):
#   struct hash_table: hasher@48 comparator@56 data_freer@64; the payload
